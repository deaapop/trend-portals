# Trend Portals

Public GitHub Pages site (Jekyll + minima) for the Brazilian Portuguese and Indonesian trend portals.

- **Do not edit `_posts/` by hand**: articles are written by the private `trend_localizer` pipeline,
  reviewed by a human, then pushed here through the GitHub contents API.
- `feed.xml` and `sitemap.xml` are regenerated by the pipeline's `syndicate` step.
- Site scaffolding (config, layouts, portal pages) comes from `trend_localizer/site_template` and is
  re-applied by `deploy_pages.ps1` without touching existing posts.
